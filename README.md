# Речевой атлас «В магазине»

Лексический раздел учебного модуля РКИ для китайских студентов.

212 карточек в восьми тематических группах: иллюстрации, китайские эквиваленты, значения, формы и примеры. Режимы: знакомство, картинка → слово, слово → значение. Поиск и фильтр материала А/Б/В.

Сайт статический: `index.html`, `style.css`, `app.js`, `cards.json`, файлы иллюстраций рядом с HTML. Для локального просмотра: `python3 -m http.server 8000`. Для GitHub Pages: ветка `main`, папка `/ (root)`.

Аудиозаписи ещё не подключены; принятый блок 1 хранится отдельно до прослушивания и нарезки. Это лексический раздел, остальные разделы атласа и тренажёр с лестницами находятся в разработке.
